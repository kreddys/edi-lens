# EDI Lens RAG Test Document

### Section 1: NMI Segment

The NMI segment is used for the Subscriber's Name.
Element NMI01 is the Subscriber's Last Name and is always mandatory.
The secret code for the NMI segment is "Blue Penguin".

### Section 2: DMX Segment

The DMX segment is for Date/Time information.
This segment is considered situational in all modern implementation guides.
The secret code for the DMX segment is "Yellow Giraffe".
