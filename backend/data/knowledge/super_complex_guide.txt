This document outlines several required modifications for the 837P X222A1 schema.

---

### Section 1: Billing Provider Name (Loop 2010AA)

The Billing Provider is identified in loop 2010AA. Within this loop, the NM1 segment's NM102 element (Entity Type Qualifier) is situational but it is a business requirement that it must be required.

---

### Section 2: Subscriber Name (Loop 2010BA)

For the Subscriber's NM1 segment, the list of valid codes for the NM101 element must be expanded. In addition to 'IL', it must also accept the code 'QC' for patient relationships.

---

### Section 3: Claim Information (CLM)

The CLM segment is critical. Its second element, CLM02 for the Total Claim Charge, must always be required. Furthermore, the base definition of the CLM segment is missing the crucial 'Release of Information' element, CLM09. This element must be added to the definition. It should be situational.
